# Learning Cybersecurity from Zero – Building Mental Models

This repository documents a **mental-model–based learning system**
designed to study cybersecurity from first principles.

The focus is not memorization, but understanding how systems behave,
fail, and interact under uncertainty.

## Who this is for
- Career switchers
- Adult learners starting later
- Self-taught students stuck despite studying
- Learners who want to understand systems, not memorize commands

## Who this is NOT for
- Shortcut seekers
- Passive learners
- Motivation-only content consumers

## The Method
The system is based on:
- error-driven learning
- diagnostic testing
- visible reasoning gaps
- controlled progression (70–75% understanding threshold)
- continuous mental model rebuilding

This is a working framework. Its value comes from use, not agreement.
